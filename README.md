# HK-Green-15 — แดชบอร์ดเครื่องผลิตเม็ดไฮโดรเจลไคโตซาน-ไบโอชาร์

เว็บ: https://tanachat007.github.io/hk-green-15/

บน GitHub Pages ใช้ตัวจำลองที่รันในเบราว์เซอร์ (จำลองเฟิร์มแวร์ Arduino Mega ทั้งรอบการผลิต) บันทึกการทดลองเก็บไว้ในเบราว์เซอร์ของผู้ใช้
ถ้าจะต่อกับเครื่องจริงผ่าน USB ให้รัน `python3 server.py` ในโฟลเดอร์โปรเจกต์แล้วเปิด http://localhost:8080

แท็บ "โมเดล 3 มิติ" แสดงโมเดลจาก Fusion 360 (STEP → GLB) ด้วย three.js
